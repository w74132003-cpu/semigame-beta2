# WaferRun｜一片晶圓的旅程

https://w74132003-cpu.github.io/semigame-beta2/

> 當一天半導體晶圓廠的製造作業員：換上防塵衣，帶著一片晶圓走完七個製程站，在時間壓力下做出每一個判斷。

WaferRun 是一款在瀏覽器裡就能玩的 3D 教學小遊戲，為高中「生活科技」與 AI／半導體相關課程設計。學生不用安裝任何東西，打開網頁就能在晶圓廠裡走動、操作機台、和同事聊天，從「自己做的決定」理解半導體製程。

**單一 HTML 檔，電腦和手機都能玩，一場約 10–15 分鐘。**

---

## 遊戲特色

- **七個製程站**：切片 → 研磨 → 塗佈顯影 → 光刻 → 蝕刻 → 量測 → 出貨，每站三個選項，各有品質與時間的代價。
- **看得到的後果**：每做一次選擇，晶圓橫切面圖就會跟著改變，選錯要重工。
- **聊天換情報**：找同事聊天可以拿到各站提示，但會花時間，被課長看到還會被唸。
- **突發事件**：地震（要原地穩住，亂跑會摔破晶圓）、客戶急件、機台警報等，練的是職場判斷，不只是背知識。
- **圖鑑**：製程名詞的白話解釋，玩之前或玩之後都能翻。
- **成績卡**：下班後產生一張成績卡，可以下載圖片或分享。
- **像素風 3D 畫面**，支援淺色與深色模式，可以開關聲音。

## 怎麼玩

| 動作 | 電腦 | 手機 |
|---|---|---|
| 移動 | `W` `A` `S` `D` 或方向鍵，也可以直接點地板 | 拖曳左下角搖桿，或點地板 |
| 互動 | 走到發亮的機台旁按 `E` | 按「互動」 |
| 聊天 | 靠近同事按 `T` | 按「聊天」 |
| 縮放 | 滑鼠滾輪 | 雙指開合 |

**目標**：跟著金色箭頭走完七站，每站選對設定，把良率拉高、準時下班。

## 開始使用

### 直接打開
下載 `waferrun.html`，用瀏覽器（Chrome、Edge、Safari、Firefox）打開就能玩。

> 需要連網：3D 引擎 Three.js 和像素字型是從網路載入的。

### 放上網路給學生玩
這是一個純靜態檔案，可以直接放到 GitHub Pages、Netlify 或學校的網頁空間，把網址或 QR Code 給學生即可。

以 GitHub Pages 為例：
1. 把 `waferrun.html` 上傳到 repo，改名為 `index.html`（或保留原名，網址加上檔名）。
2. 到 repo 的 **Settings → Pages**，Source 選擇 `main` 分支。
3. 稍等一下，就會得到 `https://<帳號>.github.io/<repo>/` 的網址。

## 課堂版（全班同時開始）

另有 **WaferRun 課堂版**（`waferrun-classroom/`）：老師開一個房間、投影房號與 QR Code，學生用手機加入，倒數後全班同時開始，老師畫面即時顯示每個人走到哪一站，結束後有頒獎台、趣味獎項和全班選擇分布，方便課後討論。使用方式請見該資料夾的 README。

課堂版的學生頁是由本檔產生的，遊戲本體只改 `waferrun.html`，再執行：

```bash
python3 mk_student.py          # 產生 waferrun-classroom/public/index.html
python3 mk_student.py --check  # 檢查學生頁是否和本檔同步
```
